Smart Queue Management System (SQMS)

📌 Project Overview

The Smart Queue Management System (SQMS) is a web-based application designed to simplify and manage queues in organizations such as Government Offices, Hospitals, Banks, and College Offices.

The system allows users to register, log in, select a service, and generate a queue token. It helps reduce physical waiting time and provides an organized way to manage and monitor queues.

🎯 Objectives

- To reduce long waiting times in government and other service offices.
- To provide a simple online token generation system.
- To organize users based on their queue tokens.
- To provide a user-friendly interface for queue management.
- To improve the efficiency of service management.
- To provide an admin dashboard for monitoring queue-related activities.

✨ Features

👤 User Registration

Users can create an account by providing the required registration details.

🔐 User Login

Registered users can securely log in to access the queue services.

🎫 Queue / Token Generation

Users can select a required service and generate a queue token.

📊 Queue Management

The system organizes generated tokens and displays queue-related information.

🛠️ Admin Module

The admin module allows administrators to monitor and manage queue information.

📍 Queue Status

Users can view their token and check the current queue status.

🏢 Available Services

The system provides queue services for:

- 🏥 Hospital
- 🏦 Bank
- 🏛️ Government Office
- 🎓 College Office

⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html".
4. Run the project using Live Server or open "index.html" directly in a browser.
5. Register as a new user.
6. Log in using the registered credentials.
7. Select a service.
8. Generate a queue token.
9. View the queue status.

💾 Data Storage

The current version uses browser LocalStorage to store user registration and queue-related information.

This project is developed as a front-end web application and does not use a Java or other server-side backend.
